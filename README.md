# Latchieu Gabriel

Grade 12 student in Toronto building data tools for the electrification of the built world.

## What I'm working on

- **[ontario-rebates](https://github.com/UnluckyCodeDev/ontario-rebates)** — A Python tool that compiles Ontario's electrification rebates (heat pumps, EV chargers, solar, panel upgrades) into a searchable dataset for contractors. Built with pandas and JSON.
- **[heat-pump-sizer](https://github.com/UnluckyCodeDev/heat-pump-sizer)** — A single-page web calculator that estimates heat pump sizing and installed cost for Toronto homes. Vanilla HTML/CSS/JS, deployed on GitHub Pages.
- **Next:** A machine learning model for heating load prediction, tied to the same electrification thesis.

## Stack

Python · pandas · JSON · Git · HTML · CSS · JavaScript
